# 託管推論加購（選配）

## 定位

- 給「不想管理 API Key／要對 VFactory 單一開票」的客戶。  
- **非預設**；主敘事維持 BYOK。

## 定價政策（對內）

- **成本轉嫁** + **固定 markup%**（對外可揭露區間）；或  
- **預付點數**，用完停機或自動加購。

## 風控

- 每公司 **硬上限**、異常偵測、信用卡預授權（若適用）。  
- 與 BYOK 帳單 **分開列示**（發票／收據備註）。

## 產品入口

- Onboarding／Billing 可放「改為託管推論」**次要 CTA**（需後端 SKU 就緒）。  
- 條款見主 GTM 文件與 ToS 修訂。
