## [Modified] ui/src/components/ChatMessageIssueRunCard.tsx
- 匯入區：加入 `useMutation`、`useQueryClient` 從 `@tanstack/react-query` 匯入，以支援在卡片中直接觸發停止執行的 mutation 並處理快取失效。
- 匯入區：新增 `Button` 由 `./ui/button` 匯入，用於渲染停止按鈕。
- 元件內部：新增 `const queryClient = useQueryClient();`，用於後續在 mutation 成功後手動 invalidation 相關快取。
- 資料查詢：新增 `useQuery` 以 `queryKeys.issues.activeRun(issue?.id ?? "")` 取得當前 Issue 的 `activeRun`，並設定 `enabled: !!issue?.id` 與 `refetchInterval: 3000`，每 3 秒輪詢最新執行情況。
- 資料合併：新增 `const effectiveRuns = activeRun ? [activeRun, ...liveRuns] : liveRuns;` 將 `activeRun` 置於 liveRuns 陣列最前端，確保顯示與 transcript 使用最新執行。
- `latestRun` 計算：由原本 `liveRuns[0]` 改為 `effectiveRuns[0]`，以支援 activeRun 被加入排序後的最新值。
- Mutation：新增 `stopIssueRun = useMutation({ ... })`，在 `mutationFn` 中檢查 `activeRun?.id` 是否存在，若存在則呼叫 `heartbeatsApi.cancel(activeRun.id)` 送出停止請求。
- Mutation：`onSuccess` 中檢查 `issue?.id` 存在後，依序 `queryClient.invalidateQueries` 針對 `queryKeys.issues.activeRun(issue.id)`、`queryKeys.issues.liveRuns(issue.id)`、`queryKeys.issues.runs(issue.id)` 做快取失效，確保 UI 反映最新狀態。
- Header 排版：原本僅單層 `span` 包含 `StatusBadge`，改為外層 `div.chat-message-issue-run-card-status-row`，內含 `StatusBadge` 與條件渲染的 Live 標記。
- Live 標記：在 `activeRun` 存在時渲染 `<span className="chat-message-issue-run-card-live-dot">`，內部包含動畫點狀元素 `chat-message-issue-run-card-live-dot-inner` 與文字 `Live`，視覺化顯示 Issue 正在執行。
- 停止按鈕：在 header 右側新增條件渲染的 `<Button>`，class 設為 `chat-message-issue-run-card-stop`，variant 使用 `ghost`、size `xs`，點擊時若 `activeRun.id` 存在且 mutation 非 pending 則呼叫 `stopIssueRun.mutate()`，並依 `stopIssueRun.isPending` 切換文案為 `t("chatIssue.stoppingIssueFromChat")` 或 `t("chatIssue.stopIssueFromChat")`，同時在 pending 狀態下 disabled 按鈕。
