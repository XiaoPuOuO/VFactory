# Change Log: 2026-04-05 06:46

## 總覽

本次變更將視覺 token 與元件樣式抽離為獨立 workspace 套件 `@paperclipai/design-system`，並讓 `ui` 應用程式透過 `index.css` 匯入該套件；同時大範圍將頁面與共用樣式中的硬編碼十六進位色改為 `oklch()` 或 `var(--…)` 語意／尺度變數，以降低重複並與設計規格一致。根目錄 `.gitignore` 新增忽略 `.superpowers/`。`pnpm-lock.yaml` 與 `ui/package.json` 已鎖定並宣告對設計系統套件的 workspace 依賴。另新增 Superpowers 計畫文件與設計系統套件原始檔（見附錄 B）。
