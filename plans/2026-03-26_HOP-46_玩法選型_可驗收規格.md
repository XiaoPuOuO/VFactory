## HOP-46（CPO）1頁玩法規格：可重複遊玩、不可簡陋

### 選型結論（A/B/C）
採用 **A：投射/射擊節奏 + 風險控管（以「防線漏怪」與「技能/彈藥管理」作為風險收益核心）**。

本款遊戲以「短局高頻」為主軸：玩家在每局 1–3 分鐘內做出連續的小判斷（站位移動、換彈/武裝切換、技能釋放時機、連擊維持），並透過隨機事件與 Boss 讓每次重玩仍有差異。

---
### 1. 核心目標（玩家要做什麼）
玩家扮演星塵要塞的近防單兵，在被敵潮壓迫時完成兩種任務之一：
1. **戰役模式（Campaign）**：在限時內累積到目標分數 `targetScore` 即通關。
2. **無盡模式（Endless）**：持續擊落敵潮，任一敵人越過「防線漏線」即立即失敗。

玩家透過：
- 連續擊倒提升 **連擊（Combo）**
- 連擊/關卡節奏推進 **技能能量（Skill Charge）**
- 正確運用 **技能（破空技能）** 與 **護盾/疾速強化道具**
- 規劃 **彈藥/換彈節奏** 與 **武裝選擇**
來獲得更高分數並延長存活時間。

---
### 2. 操作方式（Operation）
支援鍵盤與觸控/滑鼠（Canvas 拖曳與點擊）。

1. 移動
   - 鍵盤：`←/→` 或 `A/D`
   - 觸控/滑鼠：在畫面內 `拖曳` 移動
2. 射擊
   - 鍵盤：`Space`（射擊開關）
   - 觸控：`點擊 Canvas` 進行單發射擊（行動端友善）
3. 換彈
   - 鍵盤：`R`
4. 武裝切換
   - 鍵盤：`1` 衝鋒槍 / `2` 狙擊
5. 技能
   - 鍵盤：`Shift`（需技能充能到滿）
6. 暫停/重試
   - 目前以「結果面板」提供 `重試本關`；之後如需可加入暫停選單（不列入 M2 必做）

### 3. 得分、難度曲線與失敗條件

#### 得分來源（規則要可理解、可預期）
1. **敵人獎勵（Base Reward）**
   - Drone：150
   - Meteor：95
   - Boss：320
2. **戰階倍率（Rank）**
   - `rank = 1 + floor(score / 840)`（隨分數提升，間接提升敵潮強度）
   - 實作時獎勵可用：`base = reward + floor(rank * 6)`
3. **連擊加成（Combo Bonus）**
   - 若在 `1.45s` 內持續擊倒可提升 combo（上限 30）
   - `comboBonus = floor(base * min(0.18, combo * 0.015))`
4. **技能能量（Skill Charge）**
   - Boss 擊倒：技能充能顯著增加
   - 一般擊倒：依 combo 提供較小的充能增益
   - 技能充能滿後可按 `Shift` 釋放貫穿破空技能（對鍵控的「時機」形成策略）

#### 難度曲線（避免一次性暴衝）
1. Campaign（3 關卡）
   - 每關提供固定的 `timeLimitSec` 與節奏倍率：
     - `spawnMul`：敵生成間隔
     - `enemySpeedMul`：敵人速度
2. 節奏事件（Campaign 核心重玩差異）
   - 依分數分段觸發隨機事件（例：`surge / drop / jam`）
   - 每個事件影響至少 2 個維度（生成節奏、額外壓力、道具掉落率、玩家體感/射擊手感）
3. Boss（可預判但不拖戲）
   - 依分數/波次觸發 Boss 出現
   - Boss 必須具備「可見 telegraph」（例如明顯的蓄能/警示效果），讓玩家能做出合理閃避與技能釋放決策

#### 失敗條件（讓玩家知道自己輸在哪）
1. Campaign
   - 生命耗盡（`lives <= 0`）即失敗
   - 時間耗盡且未達目標分數（`levelTimeLeft <= 0` 且 `score < targetScore`）即失敗
2. Endless
   - 生命耗盡即失敗
   - 任一可漏敵人越過「防線漏線」即失敗

---
### 4. 重玩性機制（為何願意再玩一次）
1. **隨機事件（可控範圍內）**
   - 每次戰局事件類型/時點不同，但持續時間與影響強度需在可調參數內（確保可學習而不是純運氣）
2. **Boss 節奏**
   - Boss 觸發頻率隨進度/波次提升，並帶來「技能釋放時機」的策略差異
3. **連擊 → 技能**
   - 技能釋放不是冷卻硬等，而是由玩家表現（連擊與擊倒節奏）間接決定，形成技能樹外的玩法深度
4. **武裝與外觀負載（Loadout）**
   - 至少兩種武裝（不同射速/裝填/傷害與手感）
   - 外觀可選但不得犧牲讀取辨識（HUD 與敵我顏色對比需保護可讀性）
5. **目標式成就（Best + 解鎖）**
   - 每關保留 `本關最佳分數`；通關解鎖下一關或提供可持續挑戰（Endless）

---
### 5. M1 / M2 最小可行內容（避免範圍膨脹）
#### M1 — 核心玩法可玩（最小必做）
- 主選單：關卡列表（可顯示目標分數與最佳分數）
- 教學流程：關卡選擇 → 進入 intro 面板（列出操作與任務規則）
- 遊戲內 HUD：分數、最佳、生命、關卡/目標、戰階、連擊、技能能量、事件提示、限時/波次、彈藥/武裝
- 核心 loop：
  - 移動（鍵盤+觸控）
  - 射擊、換彈、武裝切換、技能釋放
  - 敵人生成、擊倒計分
- 結算面板：勝利/失敗原因清楚呈現 + `重試本關` +（若 Campaign）`下一關`

#### M2 — 重玩性與節奏（最小必做）
- 隨機事件（至少 3 種）並確保事件影響「玩家決策」而非僅是視覺差異
- 連擊系統（可視化）與技能充能（技能不是純數字冷卻）
- Boss（可見 telegraph + 明確的攻擊結果）
- 無盡模式：至少 1 條難度相位曲線（前中後）與「漏線失敗」機制
- 基本視覺回饋：命中粒子、爆破/受擊效果、屏幕細節（維持 Apple HIG：一致、克制、易讀）

### 6. UI文案與教學流程草稿（CPO 文案）

#### (1) 主選單 Overlay：`#panelStage`
- 標題：`選擇關卡`
- 內文：每關有獨立目標分數；通關後解鎖下一關。進度會儲存在本機瀏覽器。
- CTA：`進入無盡模式`
- 視覺提示：`戰階會隨分數上升，影響敵潮強度；無盡模式採波次清場，漏怪即敗。`

#### (2) 教學/進場 Overlay：`#panelIntro`
- 標題（關卡標題為動態）：`星塵要塞：回聲迴旋`（或各關自訂）
- 內文（動態填入目標/限時）：`目標分數 X、限時 Y 秒。擊落回聲飛彈、躲避外侵，並撿取護盾/疾速強化道具。`
- 操作清單（必須精簡但覆蓋關鍵）
  - `開始：按 Enter 或點擊畫面`
  - `移動：左右鍵 / A、D（或用滑鼠/觸控拖曳）`
  - `射擊：按空白鍵（連續）或點擊畫面（單發）
空彈匣需 R 換彈`
  - `武裝：1／2 切換（不同射速與手感）`
  - `連擊：快速擊落可充能技能`
  - `破空技能：按 Shift（滿能量、具貫穿）`
  - `通關：達成本關目標分數`

#### (3) 結算 Overlay：`#panelResult`
- 成功標題：`關卡通關`
- 失敗標題（兩種語意要清楚）：
  - `時間耗盡`（限時內未達目標）
  - `防線失守`（Endless 漏線）或 `防線破裂`（依實作命名）
- 失敗原因內文：一定要包含「目前分數/剩餘時間（或波次）/本關最佳」至少一項
- CTA：
  - `重試本關`
  - `下一關`（Campaign 且未完成）
  - `關卡選擇`

### 8. 工程驗收補充（CPO 建議，避免卡在驗收）
為符合 HOP-46 的工程品質驗收，建議工程端在實作時至少包含：
1. **音效**：命中、受擊、換彈、技能釋放（可用 WebAudio 即時計算音色，避免額外資產）
2. **Seed / 可重現性**：
   - 每次 run 生成 `seed`
   - 在結果面板顯示 `seed` 或提供「重播」入口（至少要能在 QA 時重現）
3. **單元測試（關鍵純函數）**：
   - 分數結算/連擊加成/事件影響倍率計算
   - wave/config 生成（如果存在可測的計算邏輯）
